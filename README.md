# 🏃 Runner — первый игровой проект

**Runner** — учебная игра в жанре раннер, созданная на **Unreal Engine**. Это мой первый игровой проект, опубликованный на GitHub.

## 🎮 О проекте

Проект посвящён знакомству с разработкой игр в Unreal Engine: работе с Blueprints, игровыми сценами и ресурсами. В репозитории собраны основные файлы раннера, а также материалы, модели и эффекты для оформления игрового окружения.

## 🛠 Технологии

- **Unreal Engine** — игровой движок.
- **Blueprints** — визуальное программирование.
- **Starter Content** — дополнительные ресурсы для оформления.

## 📁 Содержимое репозитория

| Папка | Содержимое |
| --- | --- |
| `Content` | Игровой контент, персонаж, Blueprints и карты |
| `Config` | Конфигурация проекта |
| `Audio` | Аудиоресурсы |
| `Blueprints` | Дополнительные Blueprint-объекты и эффекты |
| `Materials` | Материалы |
| `Props` и `Shapes` | Объекты окружения и базовые формы |
